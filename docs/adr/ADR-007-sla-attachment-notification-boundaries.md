# ADR-007：SLA、附件与通知边界

状态：Accepted for P1 Demo

## 决策

- SLA 策略独立存放于 `wo_sla_policy`，新工单在创建时固化响应与解决时限；工作日历计算是纯领域服务。
- SLA 检查是幂等用例，通过稳定状态避免重复升级；Demo 由 API/页面触发，生产应由高可用调度器调用。
- 附件元数据、哈希、扫描状态和内容归属 WorkOrder。上传必须通过扩展名、MIME、文件签名、大小和扫描端口；下载再次执行工单数据范围鉴权。
- Demo 将不超过 5 MiB 的附件内容存于数据库，便于单机验收；生产必须替换为私有对象存储、短期签名 URL 与异步扫描隔离区。
- 通知是独立模块，业务服务只依赖 Stage Port；通知与业务动作在同一数据库事务提交。生产外部渠道应采用 Outbox，避免在业务事务中调用邮件、短信或第三方接口。

## 后果

当前实现可以验证完整业务语义、权限和失败边界，但不把同步本地 Blob、手动 SLA 检查或数据库内通知当作生产架构结论。
