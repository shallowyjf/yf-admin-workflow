# ADR-009：取消岗位授权维度

状态：已接受（I26）

## 背景

岗位和角色都绑定在用户组织成员关系上，默认岗位编码与角色职责高度重叠。但只有角色关联 Permission、DataScope、应用角色和项目角色。管理员需要同时配置二者，且流程可能按岗位、权限却按角色判断，容易产生“能成为候选人但不能操作”或相反的不一致。

## 决策

删除岗位领域模型、数据库表、API、页面和 `ORG_POSITION` 候选类型。组织内职责统一由 Role 表达；真实人事岗位如未来需要接入，只作为 HR 主数据属性，不参与平台授权判定。

候选人按用户、全局角色、组织或组织内角色解析。历史 `ORG_POSITION` 规则迁移为等价的 `ORG_ROLE`，之后所有授权与任务资格都沿同一角色链计算。

## 结果

- 管理员只需维护组织成员关系和组织内角色；
- 权限、数据范围与流程候选人共享同一职责来源；
- 角色数量可能略有增加，但语义和审计更明确；
- 迁移删除岗位成员数据，降级不保证业务数据恢复，执行前必须备份；
- ADR-002 与 ADR-004 中关于岗位的部分仅作为历史设计记录，由本决策取代。
