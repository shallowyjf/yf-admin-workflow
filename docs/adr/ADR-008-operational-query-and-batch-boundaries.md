# ADR-008：运营查询与批处理边界

状态：Accepted for P1 Demo

## 决策

- 原有列表接口保持兼容；分页能力通过独立查询用例提供。筛选、排序、DataScope、总数计算和分页均在数据库查询中完成，页面不再下载全量工单后过滤。
- 保存视图只保存无副作用的筛选参数，按 `user_id + module + name` 唯一，并在读取、更新和删除时校验所有权。视图不保存 SQL、权限结果或数据快照。
- 批量派单和催办采用“逐条重新鉴权、允许部分成功”的运营语义，每条记录返回成功或错误原因。它不是一个全有或全无的大事务。
- IAM 导入导出采用 JSON 业务记录，不导出密码哈希、内部关系主键或会话数据。导入复用单实体管理服务，所以每行仍执行稳定权限、编码、关系和审计校验。

## 后果

当前实现适合管理员可见反馈明确的中小批次。生产环境需要把大批量导入改为异步作业，增加文件留存、审批、撤销、速率限制和结果下载；跨记录强原子性需求必须另建作业事务模型，不能改变当前部分成功语义。
