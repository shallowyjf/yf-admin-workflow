# I15：质量门禁、架构 Review 与 V0.1 冻结

## 变更摘要

本轮不扩展业务状态，而是把前十四轮成果冻结为可重复验收的 V0.1 Demo Release：新增一键质量门禁、敏感信息扫描、架构依赖约束、空库迁移 + IAM 配置 + DMA 闭环验收，以及 Release/API/架构 Review/产品差距文档。

## 自动验收

```powershell
.\.venv\Scripts\python.exe scripts\quality_gate.py
.\.venv\Scripts\python.exe -m app.demo.release_smoke
```

质量门禁依次执行：

- Ruff 检查 `app`、`tests`、`migrations`、`scripts`；
- Git 跟踪文件敏感信息和禁止文件扫描；
- `pytest -W error` 全量回归，覆盖率不得低于 90%；
- `alembic check` 确认模型和 Head 无漂移。

空库验收会迁移至 Head，幂等 Seed，创建验收岗位/Permission/角色/用户及多组织成员关系，验证授权即时生效和四类 IAM 审计，然后执行 DMA 七步闭环。

## 架构回归

- 全部 Router 禁止直接 Commit、Select、Execute 和 Query。
- Workflow 核心禁止导入 IAM，组合根例外。
- User 禁止新增 `org_id`、`role_id`、`position_id`。
- WorkOrder 状态变更集中在领域模型和状态机。

## 文档与流水线

- `.github/workflows/quality.yml` 在 Push/PR 运行相同门禁。
- 新增 ADR-006、API 清单、架构 Review、Release 手册与产品差距评估。
- 健康检查迭代更新为 `I15`，README 标记 V0.1 冻结。

## 架构偏差与遗留

核心关系、状态机和依赖方向无静默偏差。安全、协作、并发、流程版本和生产运维缺口没有用 Demo 实现掩盖，已按 P0/P1/P2 进入后续五轮建议。特别是 `workorder:transfer` 已在权限目录存在但尚无转派用例，是下一阶段明确缺口。

## 验收结果

- `113 passed`，测试覆盖率 `90.87%`；Ruff、敏感信息扫描和 Alembic 漂移检查通过。
- 空库迁移得到 20 张表（含 `alembic_version`），IAM 配置即时生效，POSITION/PERMISSION/ROLE/USER 四类审计齐全，DMA 最终状态为 `CLOSED`。
- 真实页面验收通过：管理员登录态下可见 9 项权限化导航，IAM 审计可按 Permission + admin 过滤，工单中心按数据范围展示 8 条记录，Swagger UI 正确展开 System/Auth/IAM/WorkOrder/Workflow 接口。
