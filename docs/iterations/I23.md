# I23：演示级项目进度驾驶舱

## 迭代定位

本轮只建设可展示、可操作、可回归的 Demo，不建设真实项目管理系统或实时领导驾驶舱。重点验证已有租户、系统、项目和角色权限能否支撑多项目进度场景。

## 本轮完成

- 新增轻量 `pm_project_milestone` 表；
- 每个默认工程项目提供“设计审批、现场施工、接入联调、验收移交”四个演示里程碑；
- 通过里程碑权重计算项目计划完成率和实际完成率；
- 提供五类生命线系统的项目数量、整体进度和延期项目汇总；
- 甲方领导和管理员可查看跨系统全部项目；
- 项目经理、监管和平台角色按既有项目成员资格查看；
- 管理员和具备 `project:update` 的项目经理可演示更新里程碑；
- 更新行为进入 `PROJECT_MILESTONE` IAM 审计；
- 新增 `/api/lifeline/progress`、里程碑更新 API 和 `/project-progress` 页面。

## 明确不做

- 不接入真实施工计划、合同、计量、物联网或 GIS 数据；
- 不建设数据仓库、指标平台、实时计算、消息订阅或定时同步；
- 不实现复杂甘特图、关键路径、成本挣值和预测模型；
- 不把演示进度数据作为生产决策依据。

## 自动化回归

1. 默认五个项目各生成四个里程碑，Seed 重复执行不产生重复数据；
2. 甲方领导可查看五系统五项目汇总，但不能修改进度；
3. 管理员更新里程碑后，加权项目进度立即变化并记录审计；
4. 未加入新项目的项目经理不能在进度视图看到该项目；
5. 页面展示整体进度、计划偏差、延期标识和里程碑明细；
6. 既有权限、工单和流程回归继续通过。
