# I20–I28：城市生命线权限、系统数据权限与工单产品化路线

## I20：系统与项目权限展示基线（已完成）

- 五类生命线系统目录与租户订阅；
- 五类默认工程项目；
- 甲方、监管方、施工方、平台方实体组织；
- 项目参与组织、项目成员角色、默认权限矩阵；
- 全项目/本人项目只读展示和回归基线。

## I21：系统入口与项目授权闭环（已完成）

- 会话增加活动系统与活动项目，并提供 API/UI 切换；
- 用户系统入口授权、项目 CRUD、参与组织、项目成员与成员角色管理；
- 项目成员角色成为项目作用域的显式角色绑定；
- 服务端校验租户订阅、系统入口、组织功能权限、项目成员资格和成员角色权限；
- 授权链解释、成员/系统入口撤销即时失权和跨系统/跨项目负向回归。

## I22：项目工单与流程闭环（已完成）

- 工单、流程实例、流程任务显式增加 `tenant_id/application_id/project_id`；
- 创建、派单、候选人、认领、处理、转派、复核全程校验项目资格；
- 派单目标限定项目参与组织；
- 历史 Demo 工单迁移到默认供水项目；
- 项目归档只读、成员退出、跨系统伪造参数、并发认领与幂等回归。

## I23：多系统项目进度与领导驾驶舱（演示级，已完成）

- 四个默认里程碑、权重、计划与实际进度演示数据；
- 甲方领导五类生命线系统、多项目汇总；
- 管理员/项目经理更新进度，其他角色按项目授权只读；
- 跨项目可见性、更新权限和审计回归；
- 本轮不实现实时数仓、GIS、复杂统计和生产级数据同步。

## I24：应用级角色与生命线资源权限基础

- 同一用户在不同系统中的应用级角色授予；
- 业务方向总览与具体系统驾驶舱鉴权拆分；
- 城市公共、业务共享、系统私有、项目协作、汇总和模型沙箱数据空间；
- 数据集、GIS 图层、设施、API、文件、指标、模型与结果的统一资源目录；
- 资源查看/查询最小策略、授权解释和撤销即时失权。

## I25：GIS 空间、字段与导出权限

- 管网、泵站、阀门、道路、桥梁、监测点等资产组；
- 行政区划、DMA、项目红线、GIS 图层/图斑和数据集范围；
- 字段分级、隐藏、脱敏、坐标泛化和聚合；
- 查询、编辑、下载、导出与 GIS 服务权限分离；
- API、模拟空间查询和导出任务服务端鉴权。

## I26：水力模型与跨系统资源共享

- 模型、版本、场景、输入快照、运行任务、结果和报告资源；
- 采集/处理数据、模型输入、运行状态、模型详细结果和发布成果独立授权，数据血缘不传播权限；
- 编辑、运行、审核、发布职责分离；
- 服务账号、短期作用域令牌和最小资源授权；
- 水力模型受控读取 GIS 数据集、数据快照与血缘；
- 异步任务提交授权快照和结果领取实时鉴权。

## I27：数据中心授权申请与治理

- 数据权限申请、数据责任人审批、安全审批和高敏双人审批；
- 授权有效期、临时/紧急授权、自动回收和定期复核；
- 授权影响分析、策略模拟和结构化授权解释；
- 数据查询、下载、导出、共享、模型运行和拒绝审计；
- 数据质量问题与业务资源工单关联。

## I28：数据出口强制执行与生产验收

- PostgreSQL RLS、API 网关、GIS 服务、对象存储和查询引擎执行一致策略；
- 搜索、缓存、消息主题、导出任务的租户/系统/资源隔离；
- MFA/SSO、CSRF、登录限速、密钥托管和服务账号密钥轮换；
- Outbox、异步任务、监控告警、备份恢复；
- 全量权限矩阵、性能、并发、安全、灾备和人工验收包。

I24–I28 的数据模型、权限编码、API、GIS/水力模型场景和逐轮人工验收详见 `docs/SYSTEM_DATA_PERMISSION_DESIGN.md` 与 `docs/iterations/ROADMAP_I24_I28_DATA_PERMISSION.md`。

## 每轮固定回归

- Migration 升降级、空库升级和 Alembic 漂移检查；
- Seed 幂等及默认结构精确断言；
- 功能权限、资源策略、字段/空间范围正反例，跨租户/系统/项目/资源伪造参数；
- API 与服务端页面双重鉴权；
- 既有 IAM、候选人、工作流、工单、SLA、附件、通知回归；
- Ruff、敏感信息扫描、Warnings-as-errors、覆盖率不低于 90%。
