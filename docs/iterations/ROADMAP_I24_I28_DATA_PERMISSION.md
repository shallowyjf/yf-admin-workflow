# I24–I28：系统数据权限与数据中心适配路线

本路线承接 I21 系统入口、I22 项目工单和 I23 演示驾驶舱。目标是在不破坏现有权限与工单闭环的前提下，补齐真实 GIS、水力模型和数据中心所需的系统内部数据权限。

详细设计以 `docs/SYSTEM_DATA_PERMISSION_DESIGN.md` 为准。

## I24：应用级角色与资源权限基础

状态：**已完成（2026-08-28）**。已交付四张数据权限表、7 个稳定权限编码、4 类应用数据角色、6 个系统演示空间、10 个租户级演示资源、管理/查询/授权解释 API 与 `/data-resources` 演示页面。

### 目标

解决“有系统入口即获得系统内统一角色”的粗粒度问题，建立数据空间和统一业务资源的最小闭环。

### 范围

- 新增应用级角色授予，支持同一用户在不同系统中具有不同角色；
- 将业务方向总览与具体系统驾驶舱鉴权拆分；
- 建立 COMMON、DOMAIN_SHARED、APPLICATION_PRIVATE、PROJECT、AGGREGATE、MODEL_SANDBOX 数据空间；
- 建立统一业务资源目录和父子层级；
- 建立资源查看/查询最小策略与授权解释；
- Demo 种子提供供水 GIS、DMA、水力模型资源及差异化角色；
- 不接入真实 GIS 服务，不建设通用数据开发平台。

### 回归重点

- 用户拥有水力模型入口时不能读取供水 GIS 原始资源；
- 同一用户在 GIS 可编辑、在水力模型只读；
- 有功能权限无资源策略、或有资源策略无功能权限均拒绝；
- 跨租户、跨系统、跨项目资源 ID 伪造拒绝；
- 系统入口、应用角色或资源策略撤销后即时失权；
- I01–I23 全量回归继续通过。

### 人工验收

1. 管理员给 `water_manager` 配置供水 GIS 管理角色和水力模型只读角色；
2. 用户进入供水方向总览，只看到经过授权的系统卡片；
3. 在供水 GIS 查看模拟管网图层资源；
4. 进入水力模型只显示查看动作，不显示编辑和发布；
5. 撤销 GIS 资源策略后刷新页面，系统入口保留但资源列表为空；
6. 调用授权解释查看入口、角色、资源策略和最终结果。

## I25：GIS 空间、字段与导出权限

状态：**已完成（2026-08-31）**。已交付 GIS 字段目录、字段可见/脱敏/隐藏策略、角色空间范围、坐标精度、模拟设施查询、导出审计任务、7 个 GIS 权限编码和 GIS 权限预览页面；演示数据覆盖供水、排水和燃气图层。

### 目标

验证 GIS 图层、设施、空间范围、字段和导出的最小权限闭环。

### 范围

- 管网、泵站、阀门、监测点、DMA 和行政区资源；
- GIS 图层、设施集、资产组、行政区、DMA、项目红线范围；
- 图层查看、设施编辑、空间查询、敏感坐标和导出权限；
- 字段可见、隐藏、脱敏、坐标泛化和聚合策略；
- GIS 模拟查询和导出任务，服务端重复鉴权；
- 图层、字段、空间范围和导出审计；
- 为真实 WMS/WFS/WMTS/瓦片适配预留端口，不在本轮部署真实 GIS 引擎。

### 回归重点

- 只返回授权行政区、DMA、项目红线或资产组；
- 未授权字段不进入 API 响应和导出文件；
- 无精确坐标权限时不能通过查询或导出旁路获取原始坐标；
- 页面隐藏后直接调用 API 仍拒绝；
- 查询、下载和导出权限相互独立；
- 跨系统图层 ID 伪造返回 404。

### 人工验收

1. GIS 管理员创建“城北供水管网”和“关键阀门”资源；
2. 给项目经理授权城北 DMA 范围和业务字段；
3. 项目经理只能看到授权区域，关键设施坐标经过泛化；
4. 单独授权导出后生成带有效期和审计记录的演示文件；
5. 撤销导出权限，查询仍可用但新导出被拒绝。

## I26：水力模型与跨系统资源共享

### 目标

建立模型、版本、场景、运行和结果权限，并验证水力模型受控读取 GIS 数据。

### 范围

- 水力模型、版本、场景、输入快照、运行任务、结果和成果报告资源；
- 模型查看、编辑、运行、取消、结果查看/导出、审批和发布权限；
- 采集数据、处理数据、模型输入快照、运行状态、模型详细结果和发布成果独立授权；
- 数据血缘记录派生关系但不传播输入/输出权限；
- 编辑、运行、审批、发布职责分离；
- 服务账号、最小资源授权和短期作用域令牌；
- GIS 数据集跨系统共享、数据版本快照和模型血缘；
- 异步任务提交时保存授权快照，结果领取时实时鉴权；
- 本轮使用模拟计算，不建设真实水力求解引擎。

### 回归重点

- 模型编辑人员不能审批自己提交的生产版本；
- 运行人员不能修改基础模型；
- 水力模型服务账号只能读取获授权 GIS 数据集、字段和区域；
- 数据人员能查看采集/处理数据，但结果列表、详情、文件和导出均不可见；
- 运行状态查看和模型执行权限不自动授予结果查看；
- 输入授权不沿血缘传播到结果，结果授权不反向传播到原始数据；
- 共享授权到期后新调用失败，已有审计和血缘保留；
- 运行期间撤销权限后任务行为符合快照规则，结果领取重新鉴权；
- 个人账号凭据不能作为系统集成凭据。

### 人工验收

1. GIS 数据责任人发布一个供水管网数据快照；
2. 为水力模型服务账号授权指定项目、DMA 和字段；
3. 模型人员创建场景并启动模拟运行；
4. 使用数据治理人员账号确认可以查看采集/处理数据，但不能打开模型结果；
5. 审核人员审批结果并发布脱敏汇总成果；
6. 数据治理人员只能看到获授权汇总成果，仍不能查看详细结果；
7. 查看 GIS 数据版本、模型版本、操作人和结果的完整血缘；
8. 撤销共享授权后再次运行被拒绝。

## I27：数据中心授权申请与治理

### 目标

把数据权限从管理员直接配置升级为可申请、审批、到期、复核和回收的运营闭环。

### 范围

- 数据权限申请、资源、动作、用途、字段、范围、有效期和预计调用量；
- 数据责任人审批、安全审批和高敏双人审批；
- 审批通过生成 DataAccessGrant；
- 临时、紧急和长期授权；
- 到期提醒、自动回收、定期复核和紧急撤销；
- 授权影响分析、策略模拟和结构化授权解释；
- 数据质量问题通过工单关联业务资源；
- 审计查询、导出和异常授权检测基础。

### 回归重点

- 未审批申请不产生有效访问；
- 高敏导出缺少双人审批时拒绝；
- 审批人不能绕过职责分离自批高权限；
- 到期、撤销和组织/角色失效均即时回收；
- 紧急授权短时有效并产生事后复核任务；
- 资源归档后新申请和新授权被拒绝。

### 人工验收

1. 水力模型人员申请使用 GIS 管网数据；
2. 数据责任人审批普通字段，安全人员审批敏感字段；
3. 查看授权生效时间、到期时间和授权解释；
4. 发起一次高敏导出，验证双人审批；
5. 到期或管理员撤销后刷新，数据访问立即停止；
6. 查看申请、审批、使用和撤销审计。

## I28：数据出口强制执行与生产验收

### 目标

验证权限策略在真实数据出口的一致执行，并补齐生产安全与运维门槛。

### 范围

- PostgreSQL 应用过滤与 RLS 双层隔离；
- API 网关和业务服务二次鉴权；
- GIS 服务适配器或等价模拟服务；
- 私有对象存储、短期签名 URL、异步安全扫描；
- 查询引擎字段脱敏、结果限制和导出水印；
- 搜索、缓存、消息主题的租户/系统/资源隔离；
- 策略版本缓存、失效事件和即时失权；
- MFA/SSO、CSRF、登录限速、密钥托管和服务账号密钥轮换；
- Outbox、异步任务、指标、告警、备份恢复和 RPO/RTO；
- 全量权限矩阵、性能、并发、安全和灾备验收包。

### 回归重点

- 同一策略在 API、数据库、GIS、对象存储、搜索、缓存和导出一致生效；
- 缓存和旧索引不得扩大已撤销权限；
- 对象存储 Key、签名 URL、消息 Topic 和查询参数伪造均拒绝；
- 高并发查询、导出和模型任务不跨租户或重复执行；
- 审计可关联 Trace，并验证追加写或外送防篡改；
- 备份恢复后授权、资源、审计和流程状态一致。

## 每轮固定质量门禁

- Migration 升降级、空库升级和 Alembic 漂移检查；
- Seed 幂等及默认结构精确断言；
- 功能权限、资源策略、字段/空间范围正反例；
- 跨租户、系统、项目、资源、对象存储和接口参数伪造；
- API 与服务端页面双重鉴权；
- 既有 IAM、系统入口、项目、候选人、工作流、工单、SLA、附件、通知和驾驶舱回归；
- 授权撤销、到期、缓存失效和审计回归；
- Ruff、敏感信息扫描、Warnings-as-errors，覆盖率不低于 90%。

## 演示与生产边界

I24–I27 可以使用模拟数据、模拟 GIS 查询和模拟模型计算来验证权限闭环，不宣称已经建设真实 GIS、数据中台或水力求解平台。接入真实数据前至少完成 I24–I25 的 P0 能力；对外生产使用前必须完成 I28 的数据出口、安全和运维验收。
