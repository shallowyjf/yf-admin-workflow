# I11：组织管理 CRUD 与 IAM 审计

## 1. 变更摘要

组织管理从只读视图升级为完整管理闭环。系统管理员可以通过 REST API 或页面新增组织，编辑名称、类型、父级和排序，启用/停用组织，并安全删除无关联组织。所有成功写操作与业务变更处于同一事务并写入 IAM 审计日志。

## 2. 新增/修改文件

- 新增 `app/iam/admin_service.py`：组织管理用例、权限校验、层级约束和审计。
- 新增 `app/iam/router.py`、`app/iam/schemas.py`：组织 REST API。
- 修改 IAM Model/Repository：审计实体、组织查询与安全删除支持。
- 修改 Dashboard Router/Service 与组织模板：页面 CRUD 和按钮可见性。
- 新增 `migrations/versions/0007_i11_iam_audit.py`。
- 新增 `tests/test_organization_admin.py`，扩展页面、Seed、架构与健康检查回归。

## 3. 数据库迁移

新增 `sys_iam_audit_log`：记录实体类型、实体 ID、动作、操作人和前后值载荷。执行：

```powershell
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m app.iam.seed
```

Seed 新增 `system:org:create`、`system:org:update`、`system:org:status`、`system:org:delete`，只授予 `SYSTEM_ADMIN`。

## 4. 公开 Service/API 变化

- `GET /api/orgs`：组织列表。
- `GET /api/orgs/tree`：组织树。
- `GET /api/orgs/{id}`：组织详情。
- `POST /api/orgs`：新增组织。
- `PUT /api/orgs/{id}`：编辑组织和调整父级。
- `POST /api/orgs/{id}/status`：启停组织。
- `DELETE /api/orgs/{id}`：安全删除组织。

组织编码在创建后保持稳定；父级调整会同步更新所有子孙组织的 `org_path`。停用父组织前必须先停用全部下级组织，启用子组织前父组织必须已启用。删除前必须不存在子组织或成员，数据库外键继续保护业务引用。
