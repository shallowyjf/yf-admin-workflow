# I01 项目骨架与数据库基础

## 变更摘要

建立 Python 3.12、FastAPI、SQLAlchemy、Alembic、SQLite 与 pytest 基础设施。健康检查遵循 Router -> Service -> Repository，不包含任何后续业务模型。

## 新增与修改

- 应用工厂、环境配置与生命周期管理。
- SQLAlchemy Declarative Base、Engine、SessionFactory。
- Alembic 配置与空基线迁移 `0001_i01`。
- `/health` 数据库连通性检查。
- pytest、迁移、架构边界和 OpenAPI 回归。
- Python 3.12 虚拟环境与运行说明。

## 数据库迁移

- `upgrade head` 创建 Alembic 版本基线。
- I01 不创建业务表；I02 才引入 IAM 模型。
- `downgrade base` 可回退，测试数据库文件可销毁。

## 公开 Service/API

- `HealthService.check()`
- `GET /health`

## 回归清单

1. `/health` 返回 `status=ok`、`database=ok`、`iteration=I01`。
2. OpenAPI 使用配置中的应用名称。
3. I01 的共享 Base 不包含业务表。
4. Alembic 可升级到 head、回退到 base，测试库可删除。
5. Router 不直接依赖 SQLAlchemy 或提交事务。

## 与设计文档的偏差

无。电脑原有 Python 3.11.9，经确认后安装 Python 3.12.10，并在项目 `.venv` 中隔离依赖。

- 当前没有登录、权限、候选人、流程、工单或 HTML 页面。
