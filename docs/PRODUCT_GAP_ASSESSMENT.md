# 权限系统与工单中心差距评估（V0.1）

## 当前已经具备

权限系统已具备组织树、用户多组织成员关系、角色、岗位、Permission 字典、五类 DataScope、登录会话、活动组织切换、权限即时生效、安全删除约束和 IAM 审计；五类核心配置均有 REST API 与管理页面。

工单中心已具备创建、提交、派单、多人候选、竞争认领、处理、驳回/通过、关闭、数据范围查询、我的任务和动作时间线；WorkflowTask 与 WorkOrder 分离，候选规则可按用户、角色、岗位和组织解析。

因此 V0.1 适合产品演示、规则验证和后续正式系统的架构基线，但不应直接作为生产系统上线。

## P0：进入真实试点前必须完善

| 方向 | 缺口 | 建议验收标准 |
| --- | --- | --- |
| 认证安全 | 缺 CSRF、登录限速/锁定、MFA/SSO、Secure Cookie、设备会话管理和密钥托管 | OWASP 基线用例通过；接入企业 IdP；HTTPS 下 Cookie 安全属性完整 |
| 授权治理 | 授权变更无申请审批、职责分离、有效期、紧急授权和定期复核 | 高风险角色双人审批；权限可到期；完整授权链路审计 |
| 工单协作 | Seed 有 `workorder:transfer`，但没有转派用例/API；缺附件、评论、通知和 SLA | 转派保留前后责任人；附件安全扫描；超时提醒/升级可验证 |
| 并发与幂等 | 仅验证顺序竞争认领，缺数据库级版本控制、请求幂等键和来源去重 | PostgreSQL 并发测试下只成功一次；重试不生成重复工单/动作 |
| 审计合规 | 审计可查但不可防篡改，缺导出、留存、脱敏和告警 | 追加写/签名或外送日志；敏感字段策略与留存周期可配置 |
| 生产运行 | SQLite、单进程，无监控、告警、备份恢复、容量与灾备验证 | PostgreSQL 部署；指标/Trace/结构化日志；恢复演练与 RPO/RTO 达标 |

## P1：形成可用业务产品

- IAM：搜索分页、批量导入/导出、组织同步、角色模板、权限依赖/冲突、授权影响分析。
- 工单：转派、协办、催办、撤销、重开、合并/拆分、评论、附件、联系人与资产/地理位置关联。
- SLA：按类型/优先级配置响应和解决时限，工作日历、暂停计时、自动升级、通知回执。
- 流程：定义版本、草稿/发布/停用/回滚，条件网关、会签、委托/替岗及在途实例兼容策略。
- 列表体验：服务端分页、组合筛选、排序、保存视图和批量动作。

## P2：规模化增强

- 移动端/小程序、离线处理、扫码和地图调度。
- 运营指标、积压预测、SLA 趋势、权限使用分析和异常授权检测。
- 规则中心、智能派单、相似工单推荐与知识库；模型建议必须保留人工确认和审计。
- 如业务需要集团间数据隔离，再单独设计多租户；不应在现有 `org_id` 上静默叠加租户语义。

## 建议后续五轮

1. **I16 安全基线**：CSRF、限速/锁定、安全 Cookie、密码策略、企业身份接入接口与安全回归。
2. **I17 工单协作与 SLA**：转派、评论、附件、通知、催办和超时升级，消除已声明但未实现的 Transfer 权限缺口。
3. **I18 并发与幂等**：PostgreSQL、乐观锁、幂等键、来源唯一约束、并发认领/重复回调压力测试。
4. **I19 流程配置治理**：流程版本发布/回滚、条件路由、会签、委托替岗及在途实例兼容。
5. **I20 生产运维冻结**：可观测性、审计外送、备份恢复、部署流水线、容量测试和试点验收包。

优先级判断：若下一阶段仍是内部演示，可先做 I17 提升可见价值；若准备接真实用户或真实数据，应严格从 I16 开始，并把 I18/I20 作为上线门槛。
