# 权限系统与工单中心差距评估（V0.1）

## 当前已经具备

权限系统已具备组织树、用户多组织成员关系、角色、岗位、Permission 字典、五类 DataScope、登录会话、活动组织切换、权限即时生效、安全删除约束和 IAM 审计；五类核心配置均有 REST API 与管理页面。

工单中心已具备创建、提交、派单、多人候选、竞争认领、处理、转派、协作评论、催办、驳回/通过、关闭、数据范围查询、我的任务和动作时间线；WorkflowTask 与 WorkOrder 分离，候选规则可按用户、角色、岗位和组织解析。

因此 V0.1 适合产品演示、规则验证和后续正式系统的架构基线，但不应直接作为生产系统上线。

## P0：进入真实试点前必须完善

| 方向 | 缺口 | 建议验收标准 |
| --- | --- | --- |
| 认证安全 | 缺 CSRF、登录限速/锁定、MFA/SSO、Secure Cookie、设备会话管理和密钥托管 | OWASP 基线用例通过；接入企业 IdP；HTTPS 下 Cookie 安全属性完整 |
| 授权治理 | 授权变更无申请审批、职责分离、有效期、紧急授权和定期复核 | 高风险角色双人审批；权限可到期；完整授权链路审计 |
| 工单协作 | 已有转派、评论、催办、基础 SLA、附件和站内通知；生产仍需对象存储、异步扫描、外部渠道与调度器 | 大文件直传对象存储；异步扫描隔离；通知 Outbox/重试；定时 SLA 作业高可用 |
| 并发与幂等 | 仅验证顺序竞争认领，缺数据库级版本控制、请求幂等键和来源去重 | PostgreSQL 并发测试下只成功一次；重试不生成重复工单/动作 |
| 审计合规 | 审计可查但不可防篡改，缺导出、留存、脱敏和告警 | 追加写/签名或外送日志；敏感字段策略与留存周期可配置 |
| 生产运行 | SQLite、单进程，无监控、告警、备份恢复、容量与灾备验证 | PostgreSQL 部署；指标/Trace/结构化日志；恢复演练与 RPO/RTO 达标 |

## P1：形成可用业务产品

- IAM：搜索分页、批量导入/导出、组织同步、角色模板、权限依赖/冲突、授权影响分析。
- 工单：已完成转派、评论和催办；待补协办、撤销、重开、合并/拆分、附件、联系人与资产/地理位置关联。
- SLA：已支持按优先级的响应/解决时限、24X7/工作日历、幂等升级和站内回执；待补暂停计时与节假日配置。
- 流程：定义版本、草稿/发布/停用/回滚，条件网关、会签、委托/替岗及在途实例兼容策略。
- 列表体验：服务端分页、组合筛选、排序、保存视图和批量动作。

## P2：规模化增强

- 移动端/小程序、离线处理、扫码和地图调度。
- 运营指标、积压预测、SLA 趋势、权限使用分析和异常授权检测。
- 规则中心、智能派单、相似工单推荐与知识库；模型建议必须保留人工确认和审计。
- I19 已引入独立 `tenant_id` 作为 SaaS 客户隔离边界，没有在真实组织 `org_id` 上叠加租户语义；生产环境仍需 PostgreSQL RLS 二次保护。

## 建议后续五轮

1. **I16 工单协作核心（已完成）**：转派、评论、催办及双时间线一致性。
2. **I17 SLA、附件与通知（已完成）**：工作日历、时限、超时升级、附件安全约束和站内通知回执。
3. **I18 列表与运营效率（已完成）**：服务端分页、搜索筛选、保存视图、批量动作以及 IAM 批量导入导出。
4. **I19 租户与实体组织基线（已完成）**：租户主数据、租户内唯一 IAM 编码、登录租户上下文和 IAM 查询隔离。
5. **I20 城市生命线系统与项目展示基线（已完成）**：五类系统、租户订阅、工程项目、四方参与组织、项目成员角色和默认权限矩阵。
6. **I21 系统入口与项目授权闭环（已完成）**：用户系统入口、活动系统/项目上下文、项目配置、即时失权和授权链解释。

I21-I25 的系统/项目授权闭环、项目工单、领导驾驶舱、空间资源权限和 SaaS 授权治理以 `PERMISSION_WORKORDER_REQUIREMENTS.md` 与 `iterations/ROADMAP_I20_I25.md` 为权威路线。若接入真实用户或真实数据，认证安全、并发幂等和生产运维 P0 仍是上线硬门槛。
